# WebSAPE Extension - Quick Start

Get the extension running in 2 minutes.

## Steps

1. **Unzip** `extension-standalone.zip`

2. **Load into Chrome/Edge**
   - Open Chrome/Edge → `chrome://extensions/`
   - Enable "Developer mode" (top right)
   - Click "Load unpacked"
   - Select the unzipped `dist/` folder

3. **Click the extension icon** in your toolbar

4. **Open Settings** (⚙️ icon)

5. **Add your LLM API key**
   - Provider: Claude, OpenAI, etc.
   - Model: e.g., `claude-3-5-sonnet`
   - API Key: Paste your key

6. **Enter your task** in the sidebar
   - e.g., "Search for 'laptop' on Amazon"

7. **Click "Run"**
